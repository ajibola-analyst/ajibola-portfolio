## Portfolio Architecture
This website is a custom-built, lightweight, and responsive single-page application (SPA).

* **HTML5:** Semantic structuring for accessible content delivery.
* **CSS3:** Custom styling with CSS Variables, Flexbox, and CSS Grid for a fully responsive, mobile-first design system. Includes custom media queries ensuring stability up to ultra-wide 4K displays.
* **Vanilla JavaScript:** Implements dynamic, client-side project filtering to navigate the project catalog seamlessly without page reloads.
* **Deployment:** Vercel.
