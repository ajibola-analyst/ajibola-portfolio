## Featured Architecture & Projects
This portfolio aggregates several high-impact data architectures, categorized by tool and business function. Highlights include:

* **Quantitative Actuarial VaR & Fraud Detection Engine**
  An end-to-end MLOps pipeline calculating physiological pricing baselines, modeling stochastic financial risk (95% VaR) via Monte Carlo simulations, and algorithmically detecting multidimensional healthcare billing fraud using an Isolation Forest.

* **SaaS Revenue Retention & Predictive Churn Engine**
  A dual-layer BI and machine learning architecture tracking Net Revenue Retention (NRR). Features a macro-level Tableau executive dashboard and a Python/LightGBM pipeline predicting enterprise client churn via temporal survival analysis.

* **Secure Institutional Database System**
  An enterprise-grade MySQL architecture implementing bcrypt security, connection pooling, and strict role-based access control to systematically decouple business logic from UI views.

* **Global Software Sales Performance Engine**
  An interactive Power BI dashboard utilizing a Star Schema and dynamic DAX to analyze 50k+ records, engineered to track customer loyalty, billing efficiency, and enterprise revenue optimization.

* **The Anatomy of Global Mortality (2015-2025)**
  A Tableau visual narrative mapping a 10-year dataset of global mortality trends, utilizing advanced data storytelling to isolate demographic vulnerabilities.

* **Enterprise Commercial Analytics Engine**
  An end-to-end dimensional data modeling architecture built in Excel, featuring rigorous ETL processing, data validation, and dynamic KPI tracking.

* **SQL Central Park Squirrel Data Pipeline**
  A MySQL backend and Python/Pandas extraction pipeline handling messy string formats, boolean conversions, and geospatial behavioral tracking.

* **SPSS HR Attrition Drivers Analysis**
  Statistical modeling utilizing independent T-tests to identify statistically significant 24-month flight risk spikes, income gaps, and commute fatigue parameters.

* **Quantitative Risk Modeling & Biomedical Research**
  Elsevier-published probability modeling and rigorous exploratory data analysis for multi-variable clinical cohorts.
